
FMB Thaali Ezzi Sector - Starter Package

SETUP
1. Create Firebase project.
2. Enable Authentication (Email/Password).
3. Create Firestore.
4. Paste config into js/firebase-config.js.
5. Upload folder to GitHub repository.
6. Enable GitHub Pages from Settings > Pages.

RECOMMENDED COLLECTIONS
users
thaalis
assignments
routes
settings

This starter is intended as a foundation. Production features such as role-based security, drag-drop routing, notifications, and admin screens should be implemented before live use.
