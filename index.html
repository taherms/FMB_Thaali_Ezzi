Coordinate kidmat with a rotating delivery roster: admins assign turns, members manage their own drop-off address, everyone gets a reminder the day before their turn, navigates the full route from their current location, and tracks kidmat done on a shared leaderboard.

Open Dashboard Setup Guide

What this app does

  • Admins assign delivery turns to eligible members and manage roles.
  • Members get an in-app reminder when their turn is due tomorrow.
  • Every member manages their own drop-off address; shared addresses are grouped into one stop.
  • The directory opens turn-by-turn navigation in Google Maps from your current location.
  • Each member saves their own preferred delivery route order.
  • A kidmat leaderboard with charts shows turns taken and completed by each member.

How to launch on GitHub Pages

  1. Replace the sample Firebase config in the project.
  2. Enable Firebase Authentication and Firestore (Spark/free plan is enough).
  3. Push the files to GitHub and publish the repository through Pages.
  4. Open the dashboard and sign up to start using the app.
