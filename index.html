FMB Thaali Ezzi Sector

Manage thaali distribution, assign volunteers, and let each family view locations and save their preferred delivery order in one elegant dashboard.

Open Dashboard Setup Guide

What this app does

  • Admins add, edit, and remove thaali records.
  • Each user logs in with their own account and saves a personal delivery order.
  • Locations open in Google Maps and show the full route quickly.
  • Everyone is notified when a new thaali is added or a location changes.

How to launch on GitHub Pages

  1. Replace the sample Firebase config in the project.
  2. Enable Firebase Authentication and Firestore.
  3. Push the files to GitHub and publish the repository through Pages.
  4. Open the dashboard and sign up to start using the app.
